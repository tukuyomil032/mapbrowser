# 改善案・新機能アイデア集 (ja-jp)

現在の実装形態に沿って、優先度検討しやすい改善案を整理しています。

## コマンド/UX

1. プリセット適用コマンド（例: /mb preset low-latency, kiosk）。
2. URLルール検証専用モード（/mb open --check）。
3. unload状態時のクリック可能なload提案表示。
4. プレイヤー単位のコマンド履歴（/mb history）。
5. 初回運用向けセットアップウィザード（/mb setup）。

## 描画/パフォーマンス

1. 変化量に応じたタイルサイズ動的切替。
2. ポインタ周辺を優先するROI描画。
3. TPS低下時の自動品質ダウングレード。
4. ワールド単位の描画ポリシープリセット。
5. 起動時のパレットキャッシュ段階ウォームアップ。

## 安定運用

1. 監視向けrendererヘルスエンドポイント。
2. クラッシュループ時の指数バックオフ。
3. 孤立/未使用スクリーンの自動クリーンアップ。
4. 実行時設定差分の監査ログ。
5. 診断情報一括出力（/mb admin dump）。

## ローカライズ

1. コマンド出力のキー方式完全移行。
2. CIでメッセージキーの欠落検査。
3. ロケールフォールバック（ja-JP -> ja -> en）。
4. プレースホルダ方式の統一（{screen}, {fps}）。
5. 翻訳確認用プレビューコマンド。

## セキュリティ

1. DNS Rebind対策（解決IP固定）。
2. スキーム単位のdenylist設定。
3. スクリーン単位のホスト許可ルール上書き。
4. リダイレクト上限とホスト固定ポリシー。
5. URL遷移変更の管理監査ログ。

## Companion Mod/音声

1. 距離帯ごとの減衰カーブ制御。
2. 複数スクリーン音声ミックス方針。
3. Modクライアント向け音声診断HUD。
4. 低ビットレート音声モード。
5. スクリーンと音声チャネルのプロファイル化。

## API/連携

1. スクリーンライフサイクル公開イベント。
2. APIバージョニングとcapabilityフラグ。
3. 外部管理用RESTブリッジ。
4. スクリーン管理Webダッシュボード。
5. レイアウトのインポート/エクスポート。

## 永続化/データ

1. スクリーンスナップショットとロールバック。
2. 論理削除 + 保持期間ポリシー。
3. スキーマ更新マイグレーション基盤。
4. PostgreSQLバックエンド追加。
5. タイル参照整合性チェッカー。

## テスト/品質保証

1. ゴールデンフレーム回帰テスト。
2. エイリアス正規化を含むコマンド統合テスト。
3. EN/JA同等性スナップショットテスト。
4. 再生シーンベースの性能ベンチ。
5. renderer再起動カオステスト。
